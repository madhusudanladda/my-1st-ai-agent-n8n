# My 1st AI Agent (n8n)

This project is my first AI-powered agent built using **n8n**, designed to understand user queries and intelligently fetch or compute responses using connected tools and large language models.

## 🚀 Features
- Chat-based AI agent
- Uses OpenAI Chat Model for reasoning
- Maintains conversation memory
- Fetches real-time information using SerpAPI
- Performs calculations using built-in tools
- Fully built using no-code / low-code automation (n8n)

## 🧠 How It Works
1. User sends a chat message
2. AI Agent processes the request
3. Selects the right tool (search / calculator / memory)
4. Generates a contextual response

## 🛠 Tech Stack
- n8n
- OpenAI Chat Model
- SerpAPI
- Data Wrapper style AI Agent architecture

## 📦 Workflow File
Import the .json file into your n8n instance to run the agent.
